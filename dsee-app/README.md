# ZX DSEE App 0.3.1

0.3.1 修复原厂音效页面缓存不及时写盘导致的 EQ 不跟随：使用 Android 前台服务直接读取 Sony 音效管理器的真实开关及十段值，再交给原生桥接。新增 USB 主机音量向 Sony 音量服务同步，避免实体键沿用此前保存的音量。用户已确认实体键正常从 13 升至 14，EQ/DC 试听正常；48→192 kHz 实机退出界面并熄屏 30 秒，进程不变、XRUN=0、CLIPS=0、同步服务持续。详细范围和验证见 `dsee-experimental/EQ-DC.md`。

86 组原厂处理用例及两档高采样率负对照通过；修正参数来源后的 64 组精确实时转换用例通过，包括热切换与失效快照处理。热切换采用约 20 ms 平滑交接，以避开原厂链短暂空帧。0.3.0 的首次试听未通过，0.3.1 修复后由用户确认 EQ/DC 已接通。下面 0.2.0 的记录保留为此前版本验证。

桌面名称 **ZX DSEE**，包名 `com.zx.dsee`。面向本项目已配置的国行 ZX505 4.08.00、USB DAC 内核与 KernelSU 环境，保留原作者签名的 `com.zx.dac` 应用。

## 日常使用

首次打开，在 KernelSU → 超级用户允许 ZX DSEE root，然后返回 App。准备失败时可点“重试”；正常使用时无需手动刷新。

- **启用 DSEE**：开启原厂 DSEE 适配；关闭只停用 DSEE。两个功能开关均关闭才恢复原桥接。切换会短暂停顿播放。
- **应用本机 EQ/DC**：独立控制原厂 EQ/DC 跟随，具体预设在播放器音效设置中选择。
- **状态与采样率**：自动显示正在处理、直通、等待 USB/音频或关闭，以及实际 USB 输入与耳机输出。
- **启用 USB DAC**：调用已有 DAC 控制器；已处于 DAC 模式时禁用重复操作。
- **音量 / USB 设置**：打开原 ZX DAC App。

0.2.0 已移除常驻“授权并刷新/刷新状态”“修复组件”“本机状态”时间戳、“查看诊断”和底层统计。组件校验、按需准备与后台状态读取仍自动执行；仅遇到故障时展示可操作提示，不将原始命令输出显示给用户。

支持 44.1→176.4、48→192、88.2→176.4、96→192 kHz；176.4 kHz 及以上保持输入采样率直通。开关独立于 Sony 音效设置。当前调用本机原厂算法，尚未确认与原厂播放器完整 Ultimate 模式等效。

关闭界面或熄屏不会终止独立音频进程；前台服务通过常驻通知维持音效和音量同步。强制停止 App 会停止同步服务，原生音频继续运行并保留最后有效 EQ/DC 设置，界面重开后恢复同步。USB 桥接退出约 30 秒后服务自行停止。卸载 App 不会自动清除已部署组件和开关；停用前先关闭两个音效开关。整机重启后的实测仍待补充。

## 构建

```powershell
python dsee-experimental/build.py bridge arm
python dsee-app/build.py
adb -s 播放器IP:5555 install -r images/dsee-app/ZX-DSEE-0.3.1.apk
```

支持本地默认工具目录，也可设置 `JAVA_HOME`、`ZX_ANDROID_BUILD_TOOLS`、`ZX_ANDROID_JAR` 和 `ZX_NDK_TOOLCHAIN`。工具版本及源码包步骤见 仓库根目录 `README.md`。

APK 显式不可调试，javac 使用 `-g:none`、D8 使用 `--release`，构建时清理旧 classes/gen/dex，避免带入旧界面字节码。签名文件在默认忽略的 `private/android-signing/`；保留自己的密钥才能覆盖更新已安装版本。APK、签名、ZIP 对齐及 payload 哈希结果在 `images/dsee-app/`。

App 不申请网络或共享存储权限；0.3.1 增加前台服务权限用于后台控制同步，音频仍由独立原生进程处理。root 执行固定本地校验、部署和控制命令。APK 不包含 Sony 库、模型、固件或解密密钥；原生引擎保留有限内存日志、输出完整性检查与故障回退。
