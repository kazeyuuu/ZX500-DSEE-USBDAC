# USB DAC 原厂 EQ / DC 相位线性器适配

0.3.0 增加了本机原厂十段 EQ 和 DC 相位线性器，但用户反馈 EQ 不跟随、按音量键突增。0.3.1 修复后，用户确认 EQ/DC 试听正常，实体音量键从 13 正常升至 14；48→192 kHz 退出界面并熄屏验证通过。

```text
USB PCM → 上游漂移校正 → DSEE（可选）
        → 原厂十段 EQ（跟随本机设置）
        → 原厂 DC 相位线性器（跟随本机设置）→ ALSA
```

## 使用范围

在 ZX DSEE 中打开“应用本机 EQ/DC”，然后到播放器的“音效设置”中调整预设和滑块。独立原生进程约每秒读取一次配置；退出 ZX DSEE 或熄屏不影响同步。关闭该开关只停用 EQ/DC 跟随，DSEE 保持自己的选择；两个开关均关闭时恢复原桥接。

- EQ/DC：支持 44.1、48、88.2、96、176.4、192 kHz **处理端**采样率。
- 352.8/384 kHz：原厂 EQ 不支持当前调用方式，明确旁路 EQ/DC，保持输入采样率。
- DSEE：仍支持四档 USB 输入并输出至 176.4/192 kHz，随后可串联 EQ/DC。
- 播放器“直通音源”开启时，EQ/DC 跟随通路旁路；App 的 DSEE 开关仍独立控制。
- 当前只同步 EQ 和 DC，不同步黑胶处理器、动态音量、其他音效或原厂 DSEE 开关。

EQ 使用原厂算法及其增益余量，开启时整体音量可能降低；不自动提高硬件音量。最终 PCM 转换仍检查非有限样本及限制输出范围。DC 主要改变相位，听感不一定像 EQ 那样明显；不以“听感明显”代替算法运行证据。

## 原厂接口与设置

使用设备上的 32 位 `audio.primary.icx1295.so`，通过其导出的 `IIzmEffectProcessor::Create`、`IzmEffectProcessor::Open/SetParams/Process/Close` 访问 `E:Eq10` 与 `E:DcPhaseLinearizer`。显式指定交错 float32 输入、输出，检查返回采样率、格式、声道、字节数和有限样本。

0.3.0 读取原厂音效 App 的 `SoundEffectCacheData.xml`。实机已确认用户停留在页面切换到“醇美”时，原厂服务为预设 3、频段值已改变，而该 XML 仍是预设 0、全零。该缓存不能作为实时来源。

0.3.1 的 `SonyControlService` 通过 Android Binder 连接本机 `com.sony.walkman.izmaudiomanager/.IzmAudioManager`，直接读取独立的 EQ 开关、十段值、DC 开关/类型和直通音源开关。原子快照写在 App 私有目录，桥接验证完整性、范围及 5 秒有效期；失联时保留上一有效处理状态，避免因读取失败突然转旁路。原厂代码、类和曲线均不打包。

此前缓存字段仅作研究记录：

- `eq10BandPreset`：0 关闭，1–7 为预设/自定义；十个 `EQ10BAND_FREQ_*` 值每格 0.5 dB，范围 -20 至 20。
- `enabledDcPhaseLinearizer`、`dcPhaseFilterType`：A/B/C 各低/标准/高，类型值 0–8。原厂当前 UI 的 C 系列资源不开放，适配只跟随设备实际保存的选择。
- `enabledSourceDirect`：控制 EQ/DC 旁路。

固定音量便利构造器默认将 EQ 强度缩为一半。适配明确使用与原厂 FollowToMasterVolume 相同的 unityGain=1，实测 +6/-6 dB 符合设定；不添加主音量滤波器，不改变硬件音量。这里涉及固件专用的 ARM32 类型布局，仍由 4.08.00 和 HAL 哈希门槛保护。

## 音量同步修复

实机曾同时出现 USB 主机对应 13、硬件 30、Sony 服务 30；重启桥接后硬件回到 13，Sony 服务仍记着 30。原桥接只写 ALSA，未更新 Sony 服务，存在实体键重新应用旧音量的冲突。新桥接的控制线程向 App 私有文件发布主机音量、范围和当前硬件值；前台服务在连接及主机音量变化时同步 Sony 的 `setVolume`，在主机不变时保留用户本机调节。初次同步取当前硬件与主机值的较小者。已实测将 Sony 服务 30 降到 13，并读回硬件/服务均为 13；用户随后确认实体键正常从 13 升至 14。ADB 注入音量键在这台机器上未改变 Sony 音量，不能算作实体键验证。

音频数据不经过 Java 服务。Binder 与文件同步不在 PCM 线程运行。界面关闭和熄屏不影响服务；强制停止 App 会中断同步，重新打开后恢复。退出 USB 桥接后，服务在没有心跳约 30 秒时停止。

## 热切换与回退

直接更新原厂链可能返回短暂空帧。适配改成按新参数重建处理器，并以约 20 ms 余弦权重交接新旧输出，保留完整的音频块。配置读取遇到原子更新中的不完整快照时，保留上一个有效配置并重试。

处理失败、无效输出或持续欠载会尝试清除 DSEE 和 EQ/DC 选择并回退原桥接。控制器支持 `effects-on`、`effects-off`、`trial-effects` 和 `rollback`；`rollback` 清除两个功能开关。常规 App 更新只暂存组件，不自动重启音频。

## 验证

- `effects_offline.c`：86 组初始化/处理用例，覆盖六档支持采样率的 EQ 关闭/平坦/提升/降低、九个 DC 类型及串联，加上两档高采样率的纯旁路。
- 数值检查：六档下 ±6 dB 的实际正弦增益误差小于 0.15 dB；各 DC 类型产生不同的低频相位响应；全部输出有限、完整、末端哨兵不变。
- DC 的有限长度脉冲结果不能直接作为严格全通响应或模拟输出等效性证明，本轮不作此声明。
- `bridge_contract.c`：直接编入生成的实时转换代码，64 组 DSEE/EQ/DC 组合、八档采样率策略、参数热更新和直通音源切换，不打开 ALSA 设备。

原厂库、App、预编译代码及相关分析仅在本机 `private/` 保存，不包含在 APK 或源码候选中。本文件描述接口适配，不授予 Sony 组件的重新分发权利。

## 0.3.1 最终实机核验（2026-10-25）

用户确认 EQ/DC 试听正常、实体音量键为 13→14。最后一次核验在 USB 48 kHz 输入、192 kHz 输出下，同时开启原厂 EQ 与 DC B 标准：四次状态记录均为 RUNNING、FX_UNAVAILABLE=0、XRUN=0、CLIPS=0；输出能量统计确认音乐经过处理。退出界面、熄屏 30 秒后原生 PID 始终为 6143，同步服务保持前台状态，快照持续更新。熄屏过渡附近记录到一次上游缓冲高水位恢复，此后继续正常输出，未记录 ALSA 欠载。
